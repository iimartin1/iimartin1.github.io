# Mi portafolio

Sitio web personal donde presento mis proyectos, tecnologías y datos de contacto. Hecho con HTML y CSS puro.

**Ver en vivo:** https://iimartin1.github.io/

## Qué incluye
- Menú fijo con desplazamiento suave
- Tarjetas de proyectos con demo y código
- Diseño responsive con CSS Grid
- Colores centralizados con variables CSS
- HTML semántico

## Tecnologías
- HTML5
- CSS3 (Grid, Flexbox, variables)

## Lo que aprendí
- Estructurar una página con etiquetas semánticas
- Crear layouts adaptables sin media queries usando `auto-fit` y `minmax`
- Publicar un sitio personal con GitHub Pages
